Política de privacidad — Nutrym

Nutrym es una aplicación personal de seguimiento nutricional y de entrenamiento, de uso individual. No está distribuida públicamente ni tiene usuarios más allá de su único operador.

Qué datos se guardan

La app guarda datos que el usuario carga manualmente (comidas, actividad física, peso, medidas corporales) y, si el usuario conecta su cuenta de Whoop, datos de entrenamientos (tipo de actividad, duración, energía/calorías) obtenidos a través de la API oficial de Whoop mediante OAuth 2.0.

Cómo se usan los datos de Whoop

Los datos de entrenamientos obtenidos de Whoop se usan exclusivamente para calcular el balance calórico diario dentro de esta app. No se comparten con terceros, no se usan con fines publicitarios, y no se venden.

Dónde se almacenan

Los datos se almacenan en una base de datos privada (JSONBin) asociada a esta aplicación. El token de acceso a Whoop se guarda de la misma manera, para poder sincronizar entrenamientos sin requerir un nuevo inicio de sesión cada vez.

Revocar acceso

El usuario puede desconectar el acceso a Whoop en cualquier momento desde la configuración de la app, o directamente desde developer-dashboard.whoop.com, lo cual invalida el token de acceso.

Contacto

Por ser una aplicación de uso personal, cualquier consulta se resuelve directamente con su operador.
